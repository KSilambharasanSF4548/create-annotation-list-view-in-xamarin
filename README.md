# create-annotation-list-view-in-xamarin
This example demonstrates how to create an annotation list view and navigate to them on the selection using our Syncfusion&reg; PDF Viewer.
The example shows how annotations available in a PDF document can be listed and how selecting an annotation from the list navigates the PDF Viewer to the corresponding location in the document.

## Description
This example focuses on enhancing PDF navigation by presenting annotations in a list view. All annotations present in the loaded PDF document are collected and displayed to the user. When an annotation is selected from the list, the PDF Viewer automatically navigates to that annotation.
This approach makes it easier for users to review, manage, and navigate annotated documents efficiently.

## Prerequisites

Visual Studio with Xamarin support
Xamarin.Forms application
Syncfusion® PDF Viewer for Xamarin


## How It Works

A PDF document is loaded into the Syncfusion PDF Viewer.
Annotations from the document are retrieved.
The retrieved annotations are displayed in a list view.
When an annotation is selected, the viewer navigates directly to its position in the PDF.


## Use Case

Reviewing documents with multiple annotations
Quickly navigating to comments, highlights, or shapes
Improving user experience in document review applications
